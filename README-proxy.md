# CORS 代理服务器

这是一个简单的本地代理服务器，用于解决浏览器调用 AI API 时的跨域（CORS）问题。

## 使用方法

### 1. 启动代理服务器

在命令行中运行：

```bash
node proxy-server.js
```

启动成功后会显示：
```
===========================================
CORS 代理服务器已启动
监听端口: http://localhost:3000
===========================================
```

### 2. 在网页中配置

1. 打开复读机网页
2. 点击"设置"按钮（⚙️）
3. 勾选"使用代理服务器"
4. 代理服务器地址填写：`http://localhost:3000/proxy`
5. 填写其他 API 配置（Base URL、API Key、模型名称）
6. 点击"测试连接"验证是否正常

### 3. 停止服务器

按 `Ctrl+C` 停止服务器

## 什么时候需要代理？

- **不需要代理**：如果你的 API 服务商已经配置了 CORS，可以直接调用
- **需要代理**：如果浏览器控制台报类似以下错误：
  - `Access to fetch at '...' has been blocked by CORS policy`
  - `No 'Access-Control-Allow-Origin' header is present`

## 注意事项

- 代理服务器只在本机运行，不会暴露到外网
- 所有请求日志会在控制台显示
- API Key 通过代理转发，但不会被记录或保存
- 仅用于开发测试，生产环境建议使用专业的反向代理方案
